🆘 Troubleshooting
"I don't see the pencil icon to edit index.html"
Make sure you're logged into GitHub
Make sure you're on YOUR repo (EHall4444/bracket-battle)
Check that you have write access
"The logos folder didn't create"
Make sure you typed logos/README.md with the slash
The slash is what creates the folder
"Logos aren't showing on the website"
Wait 2-3 minutes for GitHub Pages to rebuild
Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
Check browser console for errors (F12 → Console tab)
"Correct % shows weird numbers"
This is normal before games are played
Will calculate correctly once game results are entered
"I messed something up"
GitHub keeps all versions! You can always revert
Go to the file → Click "History" → Find the old version → Revert
